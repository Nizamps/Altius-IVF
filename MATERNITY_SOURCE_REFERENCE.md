# Maternity package source reference

Source: `Altius IVF & Maternity - Final- Maternity.csv` supplied with this build.

The source contains these package versions and service counts:

- First Trimester: up to 12 weeks — 13 blood investigations, 1 scan, unlimited consultation — package reference ₹15,000.
- Second Trimester: 13–28 weeks — 4 blood investigations, 3 scans, unlimited consultation — package reference ₹12,000.
- Third Trimester: 29 weeks until delivery — 9 blood investigations, 2 scans, unlimited consultation — package reference ₹10,000.

The source CSV does not name the individual blood tests or scans. The tracker therefore creates numbered slots (Blood Investigation 1…N and Scan 1…N) and allows the clinical team to replace the slot label with the exact test/scan name and set its status.
